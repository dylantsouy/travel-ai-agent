# 住宿與行李節點（Itinerary Luggage Nodes）

用於正式行程的可執行性控管。行程不能只排景點，必須把影響動線的住宿、行李、早餐與集合節點列入時間表。

## 必放節點

- 每日第一列：飯店 / 住宿，包含起床、盥洗、早餐、整理行李、check out 或出門時間。
- 每日最後一列：飯店 / 住宿，包含回房、洗澡 / 整理、預計睡覺時間。
- 住宿節點：check in、check out、寄放行李、取行李、換飯店、飯店休息、使用溫泉 / 大浴場 / lounge / 酒吧 / 洗衣等設施。
- 行李節點：車站置物櫃、行李配送、退房後寄放、tour 前寄放、郊區前寄放、拿行李後前往機場。
- 交通 / 活動節點：集合點、報到、售票 / 換票、候車、月台移動、巴士站步行、回程下車點。

## 早餐與住宿設施

- 飯店含早餐：把早餐供應時間、用餐時間與最晚入場排入停留時間。
- 飯店不含早餐：安排附近早餐、便利商店、車站早餐或行程順路咖啡店。
- 飯店設施可作為正式行程，尤其是壞天氣、隔天早起或需要收尾時。
- 飯店設施涉及營業時間、最後入場、刺青限制、男女時段或清潔時段時，需查證或標記未確認。

## 行李安全規則

- 大行李不可默認帶著逛博物館、神社、海邊、山路、排隊餐廳或夜生活。
- 抵達城市、換飯店、退房後、郊區移動、參加 tour 前，先安排飯店寄放、車站置物櫃或行李配送。
- 若不確定飯店是否可寄放或車站是否有置物櫃，標記「需出發前確認」，並安排保守備案。
- 因行李需要先去飯店或車站置物櫃時，即使不是景點，也要列為一列地點並計算交通與停留時間。

## 每日收尾

- 倒數第二段優先安排飯店附近、安全、回程簡單的小酌、居酒屋、晚餐、夜景、溫泉街散步或飯店設施。
- 若隔天很早出發，收尾改成飯店設施或提早休息。
- 行李狀態與睡覺時間必須先做內部檢查；使用者可見輸出改在每日時間表與「當日行程大綱」自然呈現，不另外輸出技術型路線檢查清單。
