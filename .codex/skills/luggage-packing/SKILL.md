# 行李整理（Luggage Packing）

## 適用情境

- 提醒使用者出國 / 旅遊必帶物品
- 依據天氣、行程與活動提供衣物建議
- 特殊行程裝備提醒（如泳衣、嬰兒用品、票券等）
- 換匯與信用卡攜帶建議
- 日常用品準備（防曬、暈車藥、防蚊液等）
- 提醒違禁品與飛行安檢規定

## 行李清單規劃原則

### 1. 必備重要物品

提醒出發必須隨身攜帶的核心物品：
- 護照（確認效期大於 6 個月）、身分證件
- 訂房時使用的信用卡
- 訂機票時使用的信用卡
- 訂行程 / 票券時使用的信用卡
- 電子機票、登機資訊、訂房確認、已預訂車票 / tour / 餐廳 / 門票憑證
- 旅遊保險資料、緊急聯絡資訊、護照影本或雲端備份
- 若飯店或租車可能驗證付款卡，提醒攜帶預訂時使用的實體信用卡

### 2. 衣物與穿著建議

- **依據天氣與天數給具體數量**：根據旅行天數、過夜數、洗衣機會、氣溫、雨季、高溫或寒冷程度，列出短袖、長袖、外套、褲裙、內衣、襪子、睡衣與鞋子的建議數量。
- **基本數量邏輯**：
  - 上衣：一般抓「旅行天數」套；高溫、流汗或無洗衣時加 1 套備用。
  - 下身：短程城市旅行通常 2-3 件可輪替；寒冷或正式餐廳另加合適服裝。
  - 內衣 / 襪子：抓「旅行天數 + 1」；若有溫泉、健身房、雨天或長步行再加 1-2 套。
  - 外套：夏季帶 1 件薄外套或防曬 / 冷氣外套；春秋帶薄外套與可疊穿層；冬季帶保暖外套、圍巾、帽子或手套。
  - 鞋子：至少 1 雙防滑好走鞋；雨季或長天數可加 1 雙備用鞋或涼鞋。
- **在地購買建議**：若有必買的服飾店且行程有順路，可以「建議」使用者少帶一套，去現場買來穿。例如：去日本且路途會經過 UNIQLO、GU 時，可以推薦去買一套。注意：不要硬找，只有在行程有順且真的很推薦時才加上此建議。
- **泳衣**：確認行程中是否有玩水、海邊、溫泉或飯店泳池，提醒是否攜帶泳衣。

### 3. 特殊行程所需物品

根據使用者的具體行程提醒額外裝備：
- 已經先買好的實體票券或列印憑證。
- 有攜帶嬰兒同行時，提醒帶寶寶需要的用品（如尿布、奶粉、推車、安撫玩具等）。
- 特定活動所需裝備（如滑雪裝備、登山杖等）。
- 泳池、海邊、水上活動、部分 spa 需泳衣；日本一般裸湯溫泉 / 大浴場通常不穿泳衣，需提醒依設施規則。
- 搭船、離島、賞鯨、海上活動或容易暈車拉車時，提醒暈船 / 暈車藥。
- 高紫外線、海邊、雪地、長時間戶外或夏季城市旅行，提醒防曬乳、太陽眼鏡、帽子。
- 雨季、梅雨、颱風季或常走戶外景點時，提醒折傘、輕便雨衣、防水鞋或鞋套、塑膠袋 / 防水袋。
- 需要正式餐廳、劇院、酒吧或商務場合時，提醒一套較整齊的服裝與鞋。

### 4. 貨幣與消費準備

- **信用卡為主**：預設建議以信用卡消費為主。
- **當地貨幣換匯**：建議先換多少當地貨幣（只需先換部分金額，避免臨時需要，例如入境後交通、小吃攤、神社寺院、置物櫃、公車、計程車或無法刷卡的場合）。需同時列當地貨幣與約當台幣。
- **現金估算邏輯**：以「每人每日小額現金」加上「機場交通 / 郊區交通 / 置物櫃 / 參拜或小吃」估算。日本城市 5 天 4 夜 2 人可先抓約 ¥40,000-60,000 現金，若大量用餐或購物可刷卡則不必全額換現金。
- **交通卡**：依目的地提醒是否攜帶或設定交通 IC 卡，例如日本 Suica / PASMO / ICOCA、台灣去機場用的一卡通 / 悠遊卡、或當地地鐵卡。若手機交通卡可用，提醒先綁定與儲值。

### 5. 日常與環境對應用品

根據前往的環境與行程類型給予提醒：
- 去太陽大或海島的地方：防曬乳、太陽眼鏡、帽子、蘆薈膠。
- 行程有坐船：暈船藥。
- 行程有爬山或郊外：防蚊液、蚊蟲藥膏、長袖薄外套。
- 長途飛行或拉車：頸枕、眼罩。
- 電子用品：手機、充電器、充電線、行動電源、轉接頭 / 轉換插頭、延長線或多孔充電器、相機與記憶卡。
- 盥洗用品：牙刷、牙膏、牙線、洗面乳、保養品、刮鬍刀、梳子、髮圈、隱形眼鏡與藥水、個人藥品。若飯店不提供一次性備品或當地政策減塑，提醒自行攜帶牙刷牙膏、刮鬍刀、梳子等。
- 藥品：常備藥、腸胃藥、止痛藥、過敏藥、暈車 / 暈船藥、OK 繃、足部貼布。
- 收納：壓縮袋、髒衣袋、夾鏈袋、環保袋、小零錢包、行李秤。

### 6. 違禁品與安檢提醒

- **目的地禁帶物品**：提醒該國家 / 地區不能帶的東西（例如：肉類製品、新鮮蔬果等）。
- **飛行禁帶物品**：提醒飛機上不能帶的東西（例如：超過 100ml 液體不能放手提、行動電源及備用電池必須放手提不能託運等）。
- **回台提醒**：肉製品、含肉泡麵、肉鬆、肉乾、新鮮蔬果等不要帶回台灣；不確定的食品先查海關 / 防檢署規定。
