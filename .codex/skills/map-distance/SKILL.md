# 地圖 / 距離計算（Map & Distance）

## 適用情境

- 查詢兩個景點之間的距離與交通方式
- 規劃景點串連路線，評估是否同一天可達
- 確認機場、車站、飯店到景點的交通方式

## 查詢步驟

### 1. 確認查詢需求
- 出發地點（景點、飯店、車站名稱）
- 目的地點
- 交通方式偏好（步行 / 大眾運輸 / 計程車 / 租車）
- 是否有行李、同行人數、長輩 / 小孩、能接受的步行距離
- 是否指定自駕；若未指定，預設大眾運輸優先

### 2. 查詢交通資訊（web tool）

依 `AGENTS.md` 的「查證來源優先級」查詢。城市內路線可先用 Google Maps；郊區、班距長、末班車、指定席、票價或錯過會嚴重延誤時，優先查交通局、鐵路 / 巴士公司官方時刻表。Rome2Rio 只作城市間方向參考，不取代官方班次。

### 3. 採用交通方案

行程表只輸出已精算的「採用交通方案」，不要讓使用者在同一段交通中任選多種方式，避免選了第二方案後後續行程時間對不上。

採用方案選擇基準：

- 能銜接後續景點、餐廳最後點餐、住宿 check in / check out 與行李寄放。
- 班次明確、發車 / 抵達時間可查。
- 未指定自駕時，大眾運輸優先；若行李多、班距長、晚間回程不穩或錯過會嚴重延誤，才採用計程車 / Uber。
- 若採用方案不是最便宜，簡短說明是為了省等待時間、先放行李、避免錯過最後點餐或降低末班車風險。

交通時間必須包含步行到站、等車、轉乘、出站步行；若資料只適合估算，請標記「約」。
使用者可見的交通方式前方加圖示：`✈️` 飛機、`🚌` 公車、`🚇` 地鐵、`🚆` 火車 / 新幹線、`🚶` 步行、`⛴️` 船、`🚕` 計程車 / Grab / Uber / 包車 / 接駁車。

### 4. 大眾運輸班次精算

規劃行程時，不能只寫「地鐵 25 分」或「搭巴士前往」。請盡量查出可執行的班次：

- 路線 / 車種：例如 JR 山口線、地鐵機場線、西鐵天神大牟田線、巴士防長線。
- 發車站與下車站：包含步行到站與出站後步行時間。
- 建議班次：發車時間、抵達時間、車程。
- 備援班次：下一班或前一班可行班次；若班距長，至少列 2 班。
- 等車風險：若錯過建議班次，會延後多久，是否會壓縮後面景點或餐廳最後點餐。
- 末班車風險：晚間或郊區路線必須查末班車或保守提醒。
- 備援班次只作為錯過採用班次時的應急，不是可任選的第二方案；若改搭備援，後續行程需順延或重新計算。

若無法即時確認精準班次，欄位填「班次未確認」，並用保守交通時間與緩衝，不可把不確定班次當作已確認；必要確認項目集中放在「出發前確認」，並附官方時刻表或地圖連結，不要在每列備註重複寫「出發前需再查」。

### 4A. 連結格式

- 景點、餐廳、飯店、車站名稱首次出現時，盡量用 Markdown 連結到 Google Maps 搜尋或地點頁，例如 `[海地獄](https://www.google.com/maps/search/?api=1&query=%E6%B5%B7%E5%9C%B0%E7%8D%84%20%E5%88%A5%E5%BA%9C)`。
- 交通訂票、指定席預約、官方時刻表與營業規則優先連官方頁，例如 `[JR Kyushu 網路預約](https://www.jrkyushu.co.jp/english/booking/)`。
- 不貼裸露長網址；用短文字包住連結。

### 5. 日行程可行性評估

若使用者同時詢問多個景點，評估：
- 各景點間移動是否合理（建議每段 < 30 分鐘交通）
- 建議景點遊覽順序，最小化總移動時間
- 總交通時間、總步行時間、是否折返、末班車或航班風險
- 第一日與最後一日須納入機場交通、報到緩衝、寄放 / 領取行李時間
