# 預算試算（Budget Calculator）

## 適用情境

- 出發前試算整趟旅遊的大概花費
- 依旅遊風格（背包 / 一般 / 豪華）列出費用明細
- 幫助使用者分配各項預算

## 查詢步驟

### 1. 確認試算條件
- 目的地、天數
- 出發人數
- 旅遊風格：背包客（省錢）/ 一般 / 豪華
- 出發地（預設台灣台北）

### 2. 查詢即時資料（web tool）

依 `AGENTS.md` 的「查證來源優先級」查詢。匯率用 xe.com、Google 匯率或台銀；機票用 Google Flights、Skyscanner 或航空公司；住宿用 Booking.com、Agoda 或飯店官網；物價參考可用 Numbeo，但只作估算。

### 3. 各風格費用分析

| 費用項目 | 背包客（省） | 一般旅遊 | 豪華旅遊 |
|---------|------------|---------|---------|
| 住宿/晚（NT$） | <1,000 | 1,500-3,000 | 5,000+ |
| 餐費/天（NT$） | 300-500 | 800-1,500 | 2,000+ |
| 交通/天（NT$） | 200-400 | 400-800 | 1,000+ |
| 門票/天（NT$） | 依免費景點 | 300-600 | 1,000+ |
| 其他/天（NT$） | 100-200 | 300-500 | 1,000+ |

*以上為通用參考值，實際依目的地物價調整*

### 4. 計算邏輯

若 `travel_tools` MCP server 可用，可用 `travel_budget_estimate` 依人數、天數、晚數、匯率與結構化費用項目試算總預算與人均費用；匯率可先由 `currency-converter` 或 `travel_currency_convert` 取得。

```
機票（來回）= 查詢 Google Flights 參考均價
住宿 = 每晚均價 × (天數 - 1)
生活費 = 每日均價 × 天數
總計 = 機票 + 住宿 + 生活費
每人分攤 = 總計 ÷ 人數
```
