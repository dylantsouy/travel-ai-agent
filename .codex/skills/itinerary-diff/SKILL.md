# 行程版本差異（Itinerary Diff）

本 skill 用於比較兩份行程，或在使用者要求改版後說明「改了什麼、為什麼、影響是什麼」。預設輸出差異摘要與取捨，不重寫整份正式行程；只有使用者要求完整新版時才進入正式行程輸出。

## 使用情境

- 使用者貼上 A / B 兩版行程，要求比較差異。
- 使用者要求把既有行程改成輕鬆、緊湊、親子、背包客、豪華、雨天、高溫、購物優先或美食優先版本。
- 使用者要求「列出你改了哪些地方」「不要整份重貼」「只說差異」。
- 使用者想看版本取捨，例如預算、步行量、交通複雜度、餐廳等級、住宿舒適度或風險差異。

## 比較流程

1. 判斷輸入類型：
   - 有兩版行程：直接比較。
   - 只有原版與改版方向：先推導新版調整方案；若需要精確時間、班次或價格，依 `AGENTS.md` 查證。
   - 只有目的地與風格：改用 `itinerary-planner`，不要假裝有版本可比。
2. 保留原版限制：目的地、日期、出發地、人數、飲食禁忌、必去 / 避開項目不可因改版而消失，除非明確說明取捨。
3. 先比較使用者最在意的指標，再補完整差異。
4. 若改版會影響航班、住宿、門票、訂位、交通班次、天氣風險或預算，查最新資料或標記未確認。
5. 不要把所有未變項目重貼；只列有差異或會影響決策的內容。

## 比較面向

- 每日節奏：起床、出門、回飯店、睡覺時間與景點數量。
- 交通：大眾運輸、計程車 / Grab、包車、自駕、步行與轉乘複雜度。
- 景點：新增、移除、保留、替換與原因。
- 餐廳：採用餐廳、備選餐廳、訂位難度、繞路程度與飲食限制。
- 住宿與行李：住宿區、check in / out、寄放行李與搬運負擔。
- 預算：機票、住宿、餐費、交通、門票與 tour 差異。
- 風險：天氣、營業時間、公休日、末班車、指定席、成團條件與取消規則。

## 輸出格式

一般差異比較：

```text
## 差異結論
1-3 句說明新版最主要的取捨。

| 面向 | 原版 | 新版 | 影響 |
|---|---|---|---|

## 逐日改動
| 日期 | 保留 | 新增 / 替換 | 移除 | 原因 |
|---|---|---|---|---|

## 需要重新確認
- ...
```

若使用者要求比較多種風格，使用：

```text
| 版本 | 適合對象 | 住宿 / 交通 | 每日節奏 | 預算影響 | 最大取捨 |
|---|---|---|---|---|---|
```

## 改版原則

- 輕鬆版：減少每日景點數、增加緩衝、提早回住宿、提高計程車或飯店休息比例。
- 緊湊版：增加景點但保留必要交通與用餐緩衝，不犧牲航班、行李與營業時間可行性。
- 親子 / 長輩版：降低轉乘與步行，增加午睡、哺乳室、電梯、室內點與早回飯店。
- 背包客版：降低住宿與交通成本，檢查廉航行李、夜巴 / 票券與青旅位置。
- 高端版：提高住宿、餐飲、包車、預約與舒適度，但清楚標示預算增加。
- 雨天 / 高溫版：把戶外長時間點改為室內、商場、博物館、飯店設施或短移動行程。
