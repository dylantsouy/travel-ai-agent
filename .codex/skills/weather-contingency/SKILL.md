# 天氣備案（Weather Contingency）

本 skill 用於在既有行程上做局部天氣改排。預設只輸出受影響日期 / 區段的替代動線與差異，不重貼完整行程；若使用者要求完整新版，再接 `itinerary-output-format`。

## 使用流程

1. 判斷天氣情境：雨天、高溫、寒流、強風、雷雨、颱風、空污、雪地或海象不佳。
2. 若日期在可靠預報範圍內，查最新天氣與官方警報；若日期太遠，只用季節風險，不寫成確定預報。
3. 找出受影響活動：長時間戶外、海邊、山區、船班、纜車、露天市集、主題樂園、夜景、步行過長路段。
4. 保留原本限制：住宿、航班、行李、飲食禁忌、必去 / 避開項目與已預約活動。
5. 替換成同區或同交通軸線的室內 / 有遮蔽 / 短移動方案，避免為了避雨大幅跨區折返。
6. 若替代點涉及營業時間、票價、最後入場、訂位或交通班次，依 `AGENTS.md` 查證；查不到就標記未確認。

## 備案原則

- 雨天：優先商場、地下街、博物館、美術館、水族館、工坊、室內市場、飯店設施、短距離餐廳。
- 高溫：11:30-15:30 避免長時間戶外；安排午餐、購物、冷氣室內、交通移動或飯店休息。
- 強風 / 雷雨：避免纜車、觀景台、船班、海邊、山區與空曠戶外。
- 颱風 / 官方警報：優先建議改期、取消郊區與海上活動，改飯店周邊室內方案；把交通停駛與退改票放進出發前確認。
- 寒流 / 雪地：降低山路自駕與戶外停留，確認雪胎、路況、營業與交通停駛風險。

## 輸出格式

```text
## 天氣備案結論
1-2 句說明調整方向與最大取捨。

| 日期 / 區段 | 原安排 | 備案安排 | 影響 | 需確認 |
|---|---|---|---|---|

## 替代動線
| 地點 | 待處理事件 | 抵達 | 停留 | 出發 | 採用交通 | 備註 | 備選 |
|---|---:|---:|---:|---:|---|---|---|

## 保留與取消
- 保留：
- 改排：
- 取消 / 延後：

## 出發前確認
- ...
```

若只改單一日，替代動線可只列該日；若只是概念備案，避免假造精準班次與營業時間。
