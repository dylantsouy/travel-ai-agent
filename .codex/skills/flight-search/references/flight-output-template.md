## 內部行程時間帶入

| 項目 | 時間 | 行程安排用法 |
|---|---|---|
| 第 1 天落地 | 12:00 | 作為首日抵達機場時間 |
| 出關 / 領行李完成 | 13:00 | 依機場規模估 45-75 分 |
| 可離開機場 | 13:10 | 從這裡計算機場到飯店 / 景點交通 |
| 最後一天起飛 | 18:40 | 作為末日倒推基準 |
| 建議抵達機場 | 15:40-16:10 | 國際線起飛前 2.5-3 小時 |
| 建議離開市區 | 14:40-15:10 | 加上前往機場交通與緩衝 |

此表只供正式行程排程時計算，不作為使用者可見段落輸出。使用者可見內容保留航班比較表，並在每日時間精算表自然呈現機場、出關、報到與離開市區節點。
