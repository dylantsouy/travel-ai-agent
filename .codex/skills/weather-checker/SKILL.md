# 天氣查詢（Weather Checker）

## 適用情境

- 查詢旅遊目的地當前天氣預報
- 詢問某個月份或季節前往是否合適
- 了解目的地氣候特性與需準備的衣物
- 依逐日 / 逐時天氣調整行程，包含雨天、高溫、暴雨、雷雨、颱風、強風與交通停駛風險

## 查詢步驟

### 1. 確認查詢需求
- 目的地城市
- 旅遊日期 / 月份

### 2. 查詢即時天氣（web tool）

依 `AGENTS.md` 的「查證來源優先級」查詢。通常先用官方氣象機構、Weather.com 或 OpenWeatherMap；只有暴雨、颱風、強風、交通停駛或資料衝突時再交叉確認第二來源。

若 `travel_tools` MCP server 可用，優先使用 `travel_weather_forecast` 查 1-14 天逐日天氣；需要確認目的地座標時可先用 `travel_geocode`。若 MCP 工具不可用、查不到、或遇到官方警報 / 高風險天氣，再依上方來源用 web 查證。

若旅遊日期太遠查不到逐日或逐時預報，不可假裝知道該天天氣；改用歷史平均氣溫、降雨量、雨季 / 颱風季與目的地氣候特性安排，必要確認日期集中放在「出發前確認」。

正式多日行程若查得到可靠逐日預報，將每日天氣與低高溫放在每日小標題同一行，例如 `### 2026/6/14（日）｜福岡 多雲 24-29°C`。若當天跨多個地區，以主要停留地為主；氣候差異明顯時可簡寫雙地。若只查得到季節平均或長期氣候，不要放在每日日期旁邊。

### 3. 旅遊季節評估

依目的地提供以下分析：
- **最佳旅遊月份**：天氣宜人、旅遊旺季
- **次佳旅遊月份**：淡季但天氣尚可，價格較低
- **建議避開月份**：颱風季、雨季、極端高溫或寒冷期

### 4. 衣物建議
依查詢到的氣溫與天氣提供具體穿著建議

### 5. 天氣驅動行程調整

- 雨天：優先建議博物館、美術館、商場、地下街、水族館、室內展望台、工坊體驗、飯店大浴場 / lounge / spa 等室內或有遮蔽行程；避免海邊、山路、長時間戶外排隊與轉乘多次的露天動線。
- 高溫 / 體感炎熱：11:30-15:30 避免沙灘、神社參道、城跡、公園、無遮蔽展望台與戶外排隊；改排冷氣室內、午餐、咖啡廳、購物、飯店休息或交通移動。
- 暴雨 / 雷雨 / 強風 / 颱風 / 官方警報：提醒使用者是否需要改期；刪除或暫停郊區、海邊、山區、船班、纜車與長距離巴士行程，改成飯店設施或市區室內備案。
- 飯店若有溫泉、大浴場、lounge、酒吧、洗衣、健身房、景觀餐廳等設施，壞天氣時可作為正式行程，而不只是備註。
- 回覆行程時只保留使用者需要知道的天氣資訊；若雨天、高溫動線已被行程處理好，不要在每列備註重複寫「早上避熱」「雨天改室內」等內部安排。只有暴雨、颱風、交通停駛或需使用者改期 / 改訂時才明確提醒。

## 輸出格式

```
## 【城市名】天氣資訊

### 當前天氣（即時查詢）
- 溫度：X°C（體感 X°C）
- 天氣：晴/多雲/小雨
- 濕度：X%
- 未來 7 天趨勢：...

### 旅遊季節指南

| 月份 | 平均氣溫 | 降雨量 | 旅遊建議 |
|------|---------|-------|---------|
| 3-5 月（春） | X-X°C | 低 | ✅ 最佳季節 |
| 6-8 月（夏） | X-X°C | 高 | ⚠️ 颱風 / 高溫 |
| 9-11 月（秋） | X-X°C | 低 | ✅ 推薦 |
| 12-2 月（冬） | X-X°C | 低 | ⚠️ 較冷 |

### 衣物建議
- 上衣：...
- 外套：...
- 鞋子：...
- 備品：雨傘 / 防曬 / ...

### 天氣與出發前確認
- 可查預報狀態：逐時預報 / 逐日預報 / 僅季節風險
- 需留意：只列會影響行程決策的高溫、豪雨、強風、颱風或交通風險
- 出發前確認：只列必要查證日期或官方天氣連結
```
