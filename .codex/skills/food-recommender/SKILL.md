# 當地美食推薦（Food Recommender）

## 目標

推薦具體餐廳、在地料理、街頭小吃、甜點、咖啡、晚間小酌與伴手禮。排入正式行程時，每餐必須有採用餐廳與 2 家備選，且能銜接前後景點。

正式餐廳表讀 `references/food-output-template.md`。

## 查詢需求

- 目的地城市與目前行程路線 / 前後景點。
- 飲食限制、預算、用餐時段、是否可排隊 / 需訂位。
- 是否有非吃不可餐廳或料理。
- 是否需要晚間收尾：飯店附近小酌、居酒屋、酒吧、夜景後餐廳或可安全回飯店的選項。

## 查證來源

依 `AGENTS.md` 的「查證來源優先級」查詢。通常先用 Google Maps 或餐廳官網；日本餐廳可加查 Tabelog；Fine Dining 或米其林查 Michelin Guide。只有最後點餐、公休、訂位、熱門排隊或資訊衝突時才查第二來源。

## 順路用餐規則

- 午餐安排在 11:30-13:30，晚餐安排在 17:30-19:30。
- 沒有指定餐廳時，先排順路景點，再找前後景點附近 10-15 分鐘步行或 1 站大眾運輸內的高評價餐廳。
- 有指定非吃不可餐廳時，以餐廳為錨點安排附近景點，但不可造成明顯折返。
- 若餐廳繞路超過 20 分鐘，標記「不夠順路」並提供替代餐廳。
- 餐廳優先選在地老店、個人店、地方料理名店或有明確特色的店；附近沒有合適餐廳、交通或營業時間受限、訂位難度太高或安全性考量時，可以使用連鎖店。若是當地非嘗試不可的特色連鎖店，也可以推薦；整趟行程不要過度依賴連鎖店。

## 排入行程時必備資訊

- 採用餐廳與 2 家備選餐廳。
- 料理類型、招牌菜、預算、營業時間、最後點餐、建議最晚抵達、是否需訂位、排隊風險與順路性。
- 主行程表地點欄寫實際店名並盡量加 Markdown 連結，待處理事件欄寫吃午餐 / 吃晚餐 / 小酌；不可只寫料理類型或「拉麵、牛舌、漢堡排」這類候選食物。
- 備選餐廳放獨立「備選」欄，不塞進備註，並盡量加 Markdown 連結。
- 備註欄寫使用者有感的特色、招牌菜、排隊策略、必買品項或需預約；不要寫內部安排話術。
- 餐廳建議最晚抵達 = 最後點餐時間 - 點餐 / 排隊緩衝；若沒有最後點餐資料，用閉店時間 - 用餐時間 - 10-15 分鐘估算。
- 預計抵達距離建議最晚抵達少於 20 分鐘時，標記「時間偏趕」並寫出錯過時改去哪家備選。
- 晚間小酌需考量最後點餐、關店時間、訂位、回飯店交通與安全性。

## 伴手禮與點心

值得買的伴手禮店、點心、零食店可以獨立列為行程地點；待處理事件寫具體品項，例如「買梅枝餅」「買博多通りもん」「買明太子仙貝」，不要只寫「買點心」。

## 輸出

- 美食清單：依必吃料理、街頭小吃、餐廳、甜點 / 咖啡、晚間小酌分類。
- 正式行程餐廳表：讀 `references/food-output-template.md`。
