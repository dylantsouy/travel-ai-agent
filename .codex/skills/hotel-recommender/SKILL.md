# 飯店住宿推薦（Hotel Recommender）

## 適用情境

- 使用者詢問「去 X 地要住哪裡」
- 依預算、風格推薦合適住宿類型
- 比較不同區域的住宿優缺點

## 查詢步驟

### 1. 確認住宿需求
- 目的地城市與偏好住宿區域
- 入住 / 退房日期、人數
- 每晚預算（台幣）
- 住宿風格（豪華飯店 / 商務飯店 / 民宿 / 青旅 / 度假村）
- 特殊需求（含早餐 / 寵物友善 / 無障礙 / 親子設施）
- check in / check out 時間、是否可提早寄放行李、退房後是否可寄放行李
- 早餐供應時間、最晚入場時間、是否適合隔天出發時間
- 飯店設施：溫泉 / 大浴場 / 酒吧 / lounge / 洗衣 / 接駁車 / 停車場 / 行李配送

### 2. 查詢住宿選項（web tool）

依 `AGENTS.md` 的「查證來源優先級」查詢。價格與評分可用 Booking.com、Agoda 或飯店官網；早餐、寄放行李、check in / out、接駁、溫泉 / 大浴場 / lounge / 洗衣等設施規則，優先查飯店官網或訂房頁說明。青旅可用 Hostelworld。

### 3. 住宿區域分析
- 說明各區域特色與交通便利度
- 推薦距離主要景點或交通樞紐近的住宿位置
- 評估飯店到車站、巴士站、tour 集合點、機場交通的實際步行與搭車時間
- 若行程有大行李，優先推薦可寄放行李、離車站近、或有接駁 / 行李配送的住宿

### 4. 各預算等級推薦

依每晚台幣預算分段推薦（背包 <NT$1,000 / 一般 NT$1,000-3,000 / 舒適 NT$3,000-6,000 / 豪華 NT$6,000+）

### 5. 行程銜接檢查

- 飯店是否含早餐；若含早餐，早餐供應時間需能銜接每日第一段交通。
- 若早餐時間太晚或不含早餐，需建議附近早餐、便利商店或車站早餐。
- check in / check out、寄放行李、取行李、使用溫泉 / 大浴場 / 酒吧等設施，都要能放進每日時間表。
- 若飯店附近晚間有安全的小酌、居酒屋、餐廳或夜景，可作為倒數第二段行程；最後一段仍須回飯店睡覺。

## 輸出格式

```
## 住宿推薦：【目的地】

### 推薦住宿選項

| 名稱 | 類型 | 區域 | 每晚（NT$） | 早餐 | check in / out | 寄放行李 | 晚間設施 / 收尾 | 評分 | 訂房連結 |
|---|---|---|---:|---|---|---|---|---:|---|
| Hotel A | 商務飯店 | 市中心 | NT$2,500 | 含，06:30-10:00 | 15:00 / 11:00 | 可寄放，需確認 | 大浴場至 24:00 | 8.7 | [Booking.com] |
| Hostel B | 青旅 | 老城區 | NT$600 | 不含 | 16:00 / 10:00 | 可寄放，需確認 | 公共 lounge | 8.2 | [Hostelworld] |

### 住宿區域建議
- **市中心**：交通最便利，但價格較高
- **老城區**：文化氛圍濃厚，步行可達主要景點

### 訂房注意事項
- 旺季提早 X 週預訂
- 確認含稅價格與取消政策
- 確認早餐時間、最晚入場、check in / out、寄放行李、設施營業時間
- 若要用飯店溫泉 / 大浴場 / 酒吧作為晚間收尾，確認最後入場與刺青 / 性別時段 / 清潔時段限制
```
