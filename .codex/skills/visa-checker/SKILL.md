# 簽證 / 入境規定查詢（Visa Checker）

## 適用情境

- 查詢台灣護照前往目的地是否需要簽證
- 了解電子簽（eVisa）或落地簽的申辦方式
- 確認護照效期、健康申報等入境要求

## 查詢步驟

### 1. 確認查詢需求
- 目的地國家
- 護照國籍（預設台灣 ROC）
- 旅遊目的（觀光 / 商務 / 過境）

### 2. 查詢官方資訊（web tool）

依 `AGENTS.md` 的「查證來源優先級」查詢。台灣護照優先查外交部領事事務局、IATA Travel Centre 或目的地移民機關；若涉及電子簽、落地簽、過境、多國籍、近期政策變動，再查目的地官方申辦網站或大使館資訊。

### 3. 分析簽證類型

| 類型 | 說明 |
|------|------|
| 免簽（Visa Free）| 憑護照直接入境，有停留天數限制 |
| 落地簽（Visa on Arrival）| 抵達機場後辦理，需準備現金、文件 |
| 電子簽（eVisa）| 出發前線上申辦，核准後才能入境 |
| 申辦簽證 | 需至大使館或透過旅行社申請 |

## 輸出格式

```
## 台灣護照前往【目的地】－簽證規定

**查詢日期**：YYYY-MM-DD
**資料來源**：外交部領事事務局 / IATA Travel Centre

### 簽證類型：[免簽 / 落地簽 / 電子簽 / 需申辦]

### 關鍵資訊
- 停留上限：X 天（觀光）
- 護照效期要求：入境時需剩餘效期 X 個月以上
- 費用：[免費 / 當地貨幣 + NT$ 換算]
- 辦理時間：[即時 / X 工作天]

### 所需文件
- [ ] 有效護照（效期 X 個月以上）
- [ ] 回程機票證明
- [ ] 訂房確認書
- [ ] 財力證明（如需）
- [ ] 照片（如需）

### 入境注意事項
- 健康 / 疫苗要求：...
- 海關申報：...
- 禁止攜帶物品：...

### 官方連結
- [外交部領事事務局](https://www.boca.gov.tw)
- [目的地國官方入境資訊]()

> ⚠️ 簽證規定時常變動，出發前請務必再次確認官方最新資訊。
```
