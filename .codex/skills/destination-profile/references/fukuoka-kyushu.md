# 福岡 / 九州北部目的地快取

用途：快速建立福岡與九州北部行程骨架。正式行程仍需查最新航班、天氣、營業時間、票價與交通班次。

## 主要機場與進城

- 福岡機場 FUK：離市區非常近，地鐵可快速到博多；首日與末日可排博多、天神、祇園、櫛田神社周邊。
- 北九州機場 KKJ：適合小倉、門司港方向，但往福岡市區較遠。

## 住宿區

- 博多：新幹線、JR、機場交通方便，適合跨城市與初訪。
- 天神：購物、餐廳、夜生活方便。
- 中洲 / 祇園：屋台、河岸、櫛田神社、博多舊城區。
- 小倉：門司港、下關、北九州動線。
- 別府 / 由布院：溫泉住宿，適合九州北部延伸。

## 常見分區

- 福岡市區：博多、天神、中洲、祇園、櫛田神社、運河城。
- 太宰府：天滿宮、參道梅枝餅、九州國立博物館。
- 門司港 / 小倉：復古港區、唐戶市場、關門海峽。
- 糸島：海邊、咖啡、夕陽；天氣與交通影響大。
- 別府：地獄巡禮、溫泉、海地獄、鐵輪。
- 由布院：溫泉街、金鱗湖、甜點與散步。

## 動線提示

- 福岡機場進出時，首末日可以保留較完整的市區輕量行程。
- 太宰府適合半日到一日，午餐與梅枝餅可放參道周邊。
- 別府 / 由布院需注意 JR / 巴士班距與指定席，正式行程務必查班次。
- 糸島、海邊與船班行程需依天氣與風速調整。
- 雨天可改博多 / 天神商場、博物館、市區美食；溫泉飯店設施可作正式行程。
