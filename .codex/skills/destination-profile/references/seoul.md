# 首爾目的地快取

用途：快速建立首爾行程骨架。正式行程仍需查最新航班、天氣、營業時間、票價與交通班次。

## 主要機場與進城

- 仁川 ICN：主要國際機場。常用 AREX 直達 / 一般列車、機場巴士、計程車。
- 金浦 GMP：離市區較近，常見東北亞區域航線。

## 住宿區

- 明洞 / 乙支路：初訪、購物、餐廳、交通方便。
- 弘大 / 延南洞：年輕、咖啡、夜生活、機場線方便。
- 江南 / COEX：商務、購物、高端餐廳。
- 鐘路 / 仁寺洞 / 北村：古宮、傳統街區、文化行程。
- 東大門：夜間購物與設計廣場。

## 常見分區

- 古宮線：景福宮、昌德宮、北村、仁寺洞。
- 明洞 / 南山：購物、南山塔、首爾站。
- 弘大 / 延南 / 合井：咖啡、設計小店、夜生活。
- 江南 / 狎鷗亭 / 聖水：精品、咖啡、潮流、COEX。
- 漢江：公園、遊船、夜景；需注意天氣與風。
- 樂天世界 / 蠶室：樂園、商場、展望台。

## 動線提示

- ICN 首日若午後抵達，排弘大、明洞、首爾站或住宿區周邊較穩。
- 末日若搭 AREX，弘大、首爾站與明洞動線較容易倒推。
- 古宮多有休館日或夜間特別開放，正式行程需查官方日期。
- 冬季寒冷、夏季高溫潮濕與雨季需調整戶外散步時間。
- 雨天可安排 COEX、百貨、博物館、地下街、咖啡廳與汗蒸幕。
