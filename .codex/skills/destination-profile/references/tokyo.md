# 東京目的地快取

用途：快速建立東京行程骨架。正式行程仍需查最新航班、天氣、營業時間、票價與交通班次。

## 主要機場與進城

- 羽田 HND：離市區近，適合首日 / 末日安排品川、濱松町、銀座、東京站、川崎或橫濱方向。
- 成田 NRT：距市區較遠，常用 Skyliner 到上野 / 日暮里、Narita Express 到東京 / 新宿 / 澀谷、利木津巴士到飯店區。

## 住宿區

- 新宿：交通最萬用，適合首次東京、夜生活與多線移動。
- 東京站 / 銀座：適合高端、購物、丸之內、機場交通與新幹線。
- 上野 / 淺草：較親民，適合成田進出、下町文化、上野公園。
- 澀谷 / 表參道：適合年輕、購物、咖啡、設計感行程。
- 舞濱：適合迪士尼，但不適合每天進市區。

## 常見分區

- 新宿 / 澀谷 / 原宿 / 表參道：購物、夜景、咖啡、年輕文化。
- 上野 / 淺草 / 藏前：寺社、下町、博物館、伴手禮。
- 東京站 / 銀座 / 築地 / 豐洲：購物、美食、市場、皇居周邊。
- 台場 / 豐洲 / TeamLab 周邊：室內展覽、海景、商場。
- 吉祥寺 / 三鷹 / 中野：公園、動畫、二手與生活感。
- 鎌倉 / 江之島 / 橫濱：一日郊區，需注意天氣與風。

## 動線提示

- 首日若 HND 中午前抵達，可排飯店寄放後銀座、東京站、品川、台場或澀谷輕量行程。
- 末日若 NRT 下午 / 傍晚起飛，優先住上野、東京站或新宿，並保守倒推機場交通。
- 雨天可用上野博物館群、銀座 / 東京站地下街、六本木美術館、豐洲 / 台場商場。
- 高溫季避免中午長時間排戶外神社、公園、皇居外苑。
