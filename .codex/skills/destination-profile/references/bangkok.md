# 曼谷目的地快取

用途：快速建立曼谷行程骨架。正式行程仍需查最新航班、天氣、營業時間、票價與交通班次。

## 主要機場與進城

- 蘇凡納布 BKK：主要國際機場。常用 Airport Rail Link、計程車 / Grab、飯店接送。
- 廊曼 DMK：廉航較多。進城常用巴士 + BTS / MRT、計程車 / Grab。

## 住宿區

- Sukhumvit / Asok / Phrom Phong：BTS / MRT 便利，餐廳、按摩、商場多。
- Siam / Chit Lom：購物核心，適合初訪與高端商場。
- Silom / Sathorn：商務、餐廳、夜生活，近河岸與 MRT。
- Riverside：高端飯店、河景、寺廟與船交通。
- Old City / Khao San：大皇宮、臥佛寺、背包客，但軌道交通較弱。

## 常見分區

- 老城寺廟：大皇宮、臥佛寺、鄭王廟；需注意服裝、日曬與排隊。
- Siam / Chit Lom：CentralWorld、Siam Paragon、Erawan、Big C。
- Sukhumvit：商場、餐廳、按摩、夜生活。
- 河岸：IconSiam、鄭王廟、晚餐遊船、飯店酒吧。
- Chatuchak / Ari：週末市場、咖啡、生活感。
- Chinatown：街頭美食與夜間行程。

## 動線提示

- 曼谷塞車嚴重，正式行程優先 BTS / MRT / 船，計程車需保守抓時間。
- 高溫季中午避免大皇宮、寺廟、露天市場長時間曝曬；早上或傍晚排戶外。
- 雨季午後雷陣雨常見，室內商場、按摩、咖啡廳與飯店設施可作正式備案。
- 寺廟需服裝規範，正式行程在備註提醒即可。
- DMK 進出若搭廉航，需更保守安排報到與市區交通。
