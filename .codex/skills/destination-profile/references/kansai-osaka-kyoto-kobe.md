# 大阪 / 京都 / 神戶目的地快取

用途：快速建立關西行程骨架。正式行程仍需查最新航班、天氣、營業時間、票價與交通班次。

## 主要機場與進城

- 關西機場 KIX：大阪、京都、神戶主要國際門戶。常用 JR Haruka、JR 關空快速、南海電鐵、利木津巴士。
- 伊丹 ITM：多為日本國內線，前往大阪市區較近。

## 住宿區

- 梅田 / 大阪站：交通樞紐，適合京都、神戶、奈良一日來回。
- 難波 / 心齋橋：購物、美食、夜生活方便，往 KIX 可用南海。
- 京都站：交通便利，適合早出晚歸與行李移動。
- 四條河原町 / 祇園：京都市區觀光方便，晚餐與散步好安排。
- 神戶三宮：神戶市區與有馬溫泉、姬路方向方便。

## 常見分區

- 大阪北區：梅田、空中庭園、天滿、中之島。
- 大阪南區：難波、道頓堀、心齋橋、黑門市場。
- 京都東山：清水寺、祇園、八坂神社、二年坂三年坂。
- 京都嵐山：竹林、渡月橋、天龍寺。
- 伏見 / 宇治：伏見稻荷、宇治平等院、抹茶。
- 神戶：北野、南京町、港區夜景、有馬溫泉。
- 奈良：東大寺、奈良公園、春日大社。

## 動線提示

- 第一次關西可用大阪作基地，安排京都 / 奈良 / 神戶一日往返；若京都深度行程多，建議至少住京都 1-2 晚。
- 首日 KIX 抵達後優先排難波、心齋橋、梅田或飯店周邊，不排京都郊區。
- 末日 KIX 起飛時，難波使用南海、梅田 / 京都使用 JR 或利木津巴士，需倒推行李與機場緩衝。
- 京都巴士容易受塞車與人潮影響，正式行程需保守排交通。
- 雨天可安排大阪商場、京都博物館 / 美術館、神戶室內景點；高溫時避開中午伏見稻荷、清水寺坡道與奈良公園長時間曝曬。
